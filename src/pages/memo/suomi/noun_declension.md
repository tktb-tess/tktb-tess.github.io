## 概要

## 凡例

| C    | 任意の子音（強階梯）あるいは備考に書かれたうちのいずれかの子音 |
| Ĉ    | 任意の子音（弱階梯）                                           |
| V    | 任意の母音                                                     |
| U    | u, y                                                           |
| O    | o, ö                                                           |
| A    | a, ä                                                           |
| N    | n, l, r                                                        |
