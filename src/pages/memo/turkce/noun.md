### 目次

## 概要

トルコ語の名詞接辞は概ね以下の順番である。

\[語幹\](-\[複数\])(-\[所有\])(-\[活用形\])-\[格\]

## 所有接辞


| :s[人称・数]{c=2} | :e   | 接辞    | 例        | 例2         |
| ----------------- | ---- | ------- | --------- | ----------- |
| :s[1人称]{r=2}    | 単数 | -(I)m   | göz-üm    | çorba-m     |
| :e                | 複数 | -(I)mIz | göz-ümüz  | çorba-mız   |
| :s[2人称]{r=2}    | 単数 | -(I)n   | göz-ün    | çorba-n     |
| :e                | 複数 | -(I)nIz | göz-ünüz  | çorba-nız   |
| :s[3人称]{r=2}    | 単数 | -(s)I   | göz-ü     | çorba-sı    |
| :e                | 複数 | -lArI   | göz-ler-i | çorba-lar-ı |

- 「3人称複数所有接辞」と「複数形接辞 + 3人称単数所有接辞」は両方 -lArI となり、区別できない。文脈で判断する。

  e.g. köpekleri「彼の犬たち」または「彼らの犬」

## 格接辞

|        | 語尾   | 例      | 例2       |
| ------ | ------ | ------- | --------- |
| 主格   | -∅     | göz     | çorba     |
| 定対格 | -(y)I  | göz-ü   | çorba-yı  |
| 与格   | -(y)A  | göz-e   | çorba-ya  |
| 処格   | -dA    | göz-de  | çorba-da  |
| 奪格   | -dAn   | göz-den | çorba-dan |
| 属格   | -(n)In | göz-ün  | çorba-nın |
| 具格   | -(y)lA | göz-le  | çorba-yla |

- 3人称単数 -(s)I および複数 -lArI の後に格接辞が来るとき、間に n が挟まる。
  e.g. kedi + -(s)I + -(格) → 主 kedisi, 定対 kedisi*n*i
