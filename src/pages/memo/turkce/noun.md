### 目次

## 概要

トルコ語の名詞接辞は概ね以下の順番である。

\[語幹\](-\[複数\])(-\[所有\])(-\[相\])-\[格\](-\[繋辞相\])(-\[人称\])

名詞に関する事項は次の通り。

- *su* は、後ろに母音で始まる接辞が付く際、間にyが挟まる。これはカッコ書きの子音より優先される。また、カッコ書きの母音で始まる接辞が付く際は、yを挟んだ上、その後に母音もつく。

  > su + -(n)In → su**y**un (❌ su**n**un)
  >
  > su + -(I)m → su**y**um (❌ sum)

## 所有接辞


| :s[人称・数]{c=2} | :e  | 接辞    | 例1      | 例2        |
| ----------------- | --- | ------- | -------- | ---------- |
| :s[1]{r=2}        | 単  | -(I)m   | göz-üm   | çorba-m    |
| :e                | 複  | -(I)mIz | göz-ümüz | çorba-mız  |
| :s[2]{r=2}        | 単  | -(I)n   | göz-ün   | çorba-n    |
| :e                | 複  | -(I)nIz | göz-ünüz | çorba-nız  |
| :s[3]{r=2}        | 単  | -(s)I   | göz-ü    | çorba-sı   |
| :e                | 複  | -lArI   | göz-leri | çorba-ları |

- 「3人称複数所有接辞」と「複数形接辞 + 3人称単数所有接辞」は両方 -lArI となり、区別できない。

  > köpekleri「彼の犬たち」または「彼らの犬」

## 格接辞

|        | 語尾   | 例1     | 例2       |
| ------ | ------ | ------- | --------- |
| 主格   | -∅     | göz     | çorba     |
| 定対格 | -(y)I  | göz-ü   | çorba-yı  |
| 与格   | -(y)A  | göz-e   | çorba-ya  |
| 処格   | -dA    | göz-de  | çorba-da  |
| 奪格   | -dAn   | göz-den | çorba-dan |
| 属格   | -(n)In | göz-ün  | çorba-nın |
| (具格) | -(y)lA | göz-le  | çorba-yla |

- 3人称単数および複数所有接辞 -(s)I, -lArI の後に具格以外の格接辞が来るとき、間にnが挟まる。具格は括弧のyをつける。

  > kedi + -(s)I + -dA → kedisi**n**de
  >
  > kedi + -(s)I + -(y)lA → kedisi**y**le (❌ kedisi**n**le)
