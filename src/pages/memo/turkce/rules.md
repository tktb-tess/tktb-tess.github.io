### 目次

## 母音調和

トルコ語には母音調和がある。接辞内の i/ı/ü/u は、直前の母音の円唇性（円唇 vs 非円唇）と舌の前後位置（前舌 vs 後舌）に同化するように交替する。また、接辞内の e/a は、舌の前後位置に同化するように交替する（円唇性には影響されない、つまり ö/o にはならない）。

継続形接辞 -Iyor の o など、同化しない母音もある。

接辞内の i/ı/ü/u をまとめて “I”、 e/a をまとめて “A” と書くことにする。

全体に共通する事項は以下の通り。

- カッコの中の子音は、直前の語幹・接辞が母音で終わる場合、追加でつく。

  e.g. uyu- + -(y)AcAk + -sIn → uyu*y*acaksın

- カッコの中の母音は、直前の語幹・接辞が子音で終わる場合、追加でつく。

  e.g. tuz + -(I)m → tuz*u*m

- 母音で終わる語幹・接辞に、母音で始まる接辞が後続する際、前の母音が脱落する。

  e.g. dinl*e*- + -Iyor + -(y)Iz → dinliyoruz

- 無声子音に有声子音で始まる接辞が後続する際、子音が無声化する。

  具体的には以下のように変化する。

  - d → t
  - c → ç

  e.g. kes- + -dI + -k → kes*t*ik

- 語幹・接辞の末子音に母音で始まる接辞が後続すると、有声化する**ことがある**。

  具体的には以下のように変化する。

  - p → b
  - t → d
  - ç → c
  - k → ğ, (nの後) g

  e.g. öğret- + -(y)AcAk + -(y)Iz → öğretece*ğ*iz (cf. öğreteceksin)

  - しないこともある。

    e.g. süt + -(y)I → sütü (× sü*d*ü)
