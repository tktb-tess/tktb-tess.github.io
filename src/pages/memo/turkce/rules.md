### 目次

## 母音調和

トルコ語には母音調和がある。接辞内の i/ı/ü/u は、直前の母音の円唇性（円唇 vs 非円唇）と舌の前後位置（前舌 vs 後舌）に同化するように交替する。また、接辞内の e/a は、舌の前後位置に同化するように交替する（円唇性には影響されない、つまり ö/o にはならない）。

継続形接辞 -Iyor の o など、同化しない母音もある。

接辞内の i/ı/ü/u をまとめて “I”、 e/a をまとめて “A” と書くことにする。

## 括弧付きの接辞について

接辞の中には、中に子音か母音が入った括弧が付いたものがある。括弧の中の子音は、直前の語幹・接辞が母音で終わる場合に追加で付き、そうでない場合は無視される。
 
> kedi + -(y)I → kedi**y**i
>
> fil + -(y)I → fili

また、括弧の中の母音は、直前の語幹・接辞が子音で終わる場合に追加で付き、そうでない場合は無視される。

> tuz + -(I)m → tuz**u**m
>
> çorba + -(I)m → çorbam

## 母音の脱落

母音で終わる語幹・接辞に、子音入り括弧がない母音で始まる接辞が後続する場合、前の母音が脱落する。

> dinl**e**- + -Iyor → dinliyor
> 
> okur- + -(y)Am**A**- + -Iyor → okuramıyor

## 無声化・有声化

無声子音に有声子音で始まる接辞が後続する際、子音が無声化する。具体的には以下のように変化する。

- d → t
- c → ç

> kes- + -dI → kes**t**i
> 
> iş + -cI → iş**ç**i

また、語幹・接辞の末子音に母音で始まる接辞が後続すると、有声化する**ことがある**。具体的には以下のように変化する。

- p → b
- t → d
- ç → c
- k → ğ, (nの後で) g

> ekmek + -(y)I → ekme**ğ**i
> 
> git- + -Iyor → gi**d**iyor

**しないこともある**ので、都度覚える。

> süt + -(y)I → sütü (❌ sü**d**ü)
>
> at- + -Iyor → atıyor (❌ a**d**ıyor)
