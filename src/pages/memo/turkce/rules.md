### 目次

## 母音調和

トルコ語には母音調和がある。接辞内の i/ı/ü/u は、直前の母音の円唇性（円唇 vs 非円唇）と舌の前後位置（前舌 vs 後舌）に同化するように交替する。

このサイトでは、接辞内の i/ı/ü/u をまとめて “I” と書くことにする。

> fil + -(y)I → fil**i**
>
> göz + -(y)I → göz**ü**
>
> kadın + -(y)I → kadın**ı**
>
> kuş + -(y)I → kuş**u**

また、接辞内の e/a は、舌の前後位置に同化するように交替する（円唇性には影響されない、つまり ö/o にはならない）。

このサイトでは、接辞内の e/a をまとめて “A” と書くことにする。

> fil + -(y)A → fil**e**
>
> göz + -(y)A → göz**e** (❌ göz**ö**)
>
> kadın + -(y)A → kadın**a**
>
> kuş + -(y)A → kuş**a** (❌ kuş**o**)

可能・推量接辞 -(y)Ab**i**l- のiや継続形接辞 -Iy**o**r のoなど、同化しない母音もある。

> iç- + -Iyor → içiy**o**r (❌ içiy**ö**r)
>
> otur- + -(y)Abil- + -Vr → oturab**i**lir (❌ oturab**ı**lır)

## 括弧付きの接辞について

接辞の中には、中に子音か母音が入った括弧が付いたものがある。括弧の中の子音は、直前の語幹・接辞が母音で終わる場合に追加で付き、そうでない場合は無視される。
 
> kedi + -(y)I → kedi**y**i
>
> fil + -(y)I → fili

また、括弧の中の母音は、直前の語幹・接辞が子音で終わる場合に追加で付き、そうでない場合は無視される。

> tuz + -(I)m → tuz**u**m
>
> çorba + -(I)m → çorbam

## 母音の脱落

母音で終わる語幹・接辞に、子音入り括弧がない母音で始まる接辞が後続する場合、前の母音が脱落する。

> dinl<span class="text-textpale">e</span>- + -Iyor → dinliyor
> 
> otur- + -(y)Am<span class="text-textpale">A</span>- + -Iyor → oturamıyor

## 無声化・有声化

無声子音に有声子音で始まる接辞が後続する際、子音が無声化する。具体的には以下のように変化する。

- d → t
- c → ç

> kes- + -dI → kes**t**i
> 
> iş + -cI → iş**ç**i

また、語幹・接辞の末子音に母音で始まる接辞が後続すると、有声化する**ことがある**。具体的には以下のように変化する。

- p → b
- t → d
- ç → c
- k → ğ, (nの後で) g

> ekmek + -(y)I → ekme**ğ**i
> 
> git- + -Iyor → gi**d**iyor

**しないこともある**ので、都度覚える。

> süt + -(y)I → sü**t**ü (❌ sü**d**ü)
>
> at- + -Iyor → a**t**ıyor (❌ a**d**ıyor)
